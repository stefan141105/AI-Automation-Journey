## CS50P Week 2 (Loops)

## Loops
A **loop** repeats a block of code multiple times.

## while
**'while'** repeats a block of code as long as condition remains 'True'.

## for 
**'for'** repeats a block of code once for each item in a sequence.

## list
A **list** stores multiple values in one variable, in a specific order.

## range()
'range()' creates a sequence of numbers, usually used with a 'for' loop to repeat code a certain number of times.

## len()
'len()' returns how many items are inside something, such as a string or list.

## break
'break' immediately stops a loop.

## continue
'continue' skips the rest of the current loop and starts the next repetition.

## Index
An **index** is the position of an item inside a sequence such as a list.

Python starts counting indexes from 0.

## +=
'+=' increases a variable by a value and stores the new result.

Example:
'x += 1'

is a shorter way of writting:
'x = x + 1'
