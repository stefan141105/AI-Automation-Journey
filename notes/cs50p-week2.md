## CS50P Week 2 (Loops)

## Loops
A **loop** repeats a block of code multiple times.

## while
**'while'** repeats a block of code as long as condition remains 'True'.

## for 
**'for'** repeats a block of code once for each item in a sequence.

## list
A **list** stores multiple values in one variable, in a specific order.
