## CS50P - Week 3 (Exceptions)

## Exceptrions
An **exception** is an error that happens while a program is running. If it is not handled, the program can stop and crash.

## SyntaxError
A **SyntaxError** happens when Python cannot understand the structure of your code because it was written incorrectly.

## RuntimeError
A **RuntimeError** is an exception that happens while the program is running when Python cannot complete an operation properly.

## ValueError
A **ValueError** happens when a function receives the correct type of value, but the value itself is not valid for the operation.

## try
'try' is used to run code that might cause an exception. Python attempts to run the code inside the 'try' block

## except 
'except' is used to handle an exception if an error happens inside a 'try' block. It lets the program respond to the error instead of crashing.

## NameError
A **NameError** happens when Python tries to use a variable or name that has not been defined.

## else with try/except
'else' runs only if the code inside the 'try' block finishes without raising an exception.

## pass
'pass' tells Python to do nothing and continue running. It is often used as a placeholder when Python requires a block of code but you do not want anything to happen there yet.

## finally
'finally' runs no matter what happens in the 'try' block, whether an exception occurs or not.

## raise 
'raise' is used to manually trigger an exception.
